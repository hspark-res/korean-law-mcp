# 로컬 조회 전용 설치

LAW_READ_ONLY=1에서 outputPath 요청은 네트워크 호출 전에 거절한다.
HTTP 평문 API 연결을 거절한다. 파일 출력이 가능한 일반 실행의 도구 표시는 읽기 전용으로 광고하지 않는다.
run.py는 Node 24 권한 모델로 저장소 내부 읽기만 허용하며 파일 쓰기, 자식 프로세스, worker, native addon 권한을 주지 않는다.
이 모델은 악성 코드에 대한 OS 수준 샌드박스가 아니다. 외부 네트워크는 제한하지 않는다.
환경은 최소 항목만 전달하고 인증키는 저장소 밖 ~/.config/korean-law-mcp/oc.key에서 읽는다.
해당 파일은 소유자 전용 600 권한이어야 하며 OC 값 한 줄만 저장한다. 키를 git에 넣지 않는다.
Codex 설정은 키 발급 전 enabled=false로 유지한다. 키 저장 후 enabled=true로 전환하고 앱에서 MCP 연결을 새로 시작한다.
버전 자동 업데이트는 하지 않는다. upstream 변경은 별도 검토 후 적용한다.
